测试前置条件:
1. 使用 go build -o sql-mgr ./cmd/server 构建二进制
2. 确保 config.yaml 存在且可读写
3. 准备一个可连通的 MySQL 数据源用于执行引擎测试
4. 准备一个可连通的 Git 仓库用于归档测试
5. 首次启动会自动创建 admin/admin123 管理员账户
